# Cursos Blatam IA

Sitio web para los cursos de Inteligencia Artificial de Blatam.

## Requisitos

- Node.js 20.18.1 o superior
- npm, yarn, o pnpm

## Instalación

### Con npm (recomendado)
```bash
npm install --legacy-peer-deps
```

### Con yarn
```bash
yarn install
```

### Con pnpm
```bash
pnpm install
```

## Desarrollo

### Con npm
```bash
npm run dev
```

### Con yarn
```bash
yarn dev
```

### Con pnpm
```bash
pnpm run dev
```

El servidor de desarrollo estará disponible en `http://localhost:3000`

## Scripts disponibles

- `dev`: Inicia el servidor de desarrollo
- `build`: Construye la aplicación para producción
- `start`: Inicia el servidor de producción
- `lint`: Ejecuta el linter

## Notas importantes

- Si encuentras problemas con las dependencias, usa `--legacy-peer-deps` con npm
- El proyecto está configurado para funcionar con Next.js 15.3.0
- Se recomienda usar Node.js 20.18.1 (especificado en .nvmrc)
